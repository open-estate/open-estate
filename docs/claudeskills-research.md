## Gaps: what none of the 21 does
- **Turn a US address into a report.** No skill geocodes an address or links it to census, flood, quake, fire, pollution, school or amenity data.
- **Hazards and pollution layers.** None uses FEMA, USGS, CAL FIRE, CGS, EPA, GeoTracker, EnviroStor or CalEnviroScreen.
- **Market history and risk.** None models value history, drawdowns, forward-return odds or forecasts.
- **Maps and visuals.** None produces maps or charts; all output is text.
- **Feng shui.** No skill computes facing direction, flying stars or form-school checks.
- **Ready for a Worker.** Most depend on a CLI (Membrane, npx, Go binaries) and can't run inside a Cloudflare Worker.

## Design decisions that came out of this research
1. **One focused skill per data domain, plus an orchestrator.** Each skill can be used alone ("is this address in a flood zone?") or in the full report.
2. **Runtime-neutral modules.** The modules use only `fetch` and keyless public APIs, with keyed providers (RentCast, data.gov) optional. This makes the move to Cloudflare Workers mechanical.
3. **CMA discipline.** Comparable sales are always cited, adjustments are explained, and the result is a range with confidence. Wording says "not an appraisal".
4. **Compliance built in.** No demographic composition, no safe/unsafe labels, crime only as agency-level facts, and school data shown but not scored (`us-property-report/references/compliance.md`).
5. **Visual-first output.** The report is one self-contained HTML page, so the Worker can return the same template plus JSON.
